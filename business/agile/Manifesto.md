# Português — Seção 3: Manifesto Ágil

## Resumo enxuto

| Tópico          | Ideia principal                                               |
| --------------- | ------------------------------------------------------------- |
| Manifesto Ágil  | Base de valores e princípios dos métodos ágeis                |
| Foco            | Entregar valor, colaborar, adaptar e aprender continuamente   |
| Não é           | Scrum, Kanban ou uma metodologia fechada                      |
| Serve para      | Orientar times em ambientes de incerteza e mudança            |
| Visão de gestão | Menos controle burocrático, mais entrega de valor e adaptação |

---

## 4 valores do Manifesto Ágil

| Valor                                                      | Significado prático                                                                |
| ---------------------------------------------------------- | ---------------------------------------------------------------------------------- |
| Indivíduos e interações acima de processos e ferramentas   | Pessoas alinhadas e colaborando importam mais que seguir ferramentas mecanicamente |
| Software funcionando acima de documentação abrangente      | Progresso real é entrega utilizável, não apenas documentação                       |
| Colaboração com o cliente acima de negociação de contratos | Cliente, negócio e time precisam construir entendimento juntos                     |
| Responder a mudanças acima de seguir um plano              | Planejar é importante, mas adaptar-se é essencial                                  |

---

## Manifesto Ágil na gestão de projetos

| Situação                   | Aplicação ágil                                                |
| -------------------------- | ------------------------------------------------------------- |
| Mudança de requisito       | Avaliar valor, impacto e ajustar o plano quando fizer sentido |
| Cliente distante           | Aproximar stakeholders do time                                |
| Muito planejamento inicial | Trabalhar com ciclos curtos e feedback frequente              |
| Documentação excessiva     | Documentar o necessário para apoiar decisão e execução        |
| Pouca entrega real         | Priorizar incrementos validáveis                              |
| Time dependente de comando | Criar autonomia com direção clara                             |

---

## O que memorizar

| Pergunta                      | Resposta curta                                                                |
| ----------------------------- | ----------------------------------------------------------------------------- |
| O que é o Manifesto Ágil?     | Conjunto de valores e princípios para desenvolver e gerir trabalho adaptativo |
| Ele elimina planejamento?     | Não; troca planejamento rígido por planejamento adaptativo                    |
| Ele elimina documentação?     | Não; prioriza documentação útil e suficiente                                  |
| Principal medida de progresso | Entrega funcionando e validável                                               |
| Maior benefício para gestão   | Aumentar adaptação, colaboração e foco em valor                               |

# English — Section 3: Agile Manifesto

## Short Summary

| Topic           | Main Idea                                                     |
| --------------- | ------------------------------------------------------------- |
| Agile Manifesto | Foundation of values and principles behind Agile methods      |
| Focus           | Deliver value, collaborate, adapt, and learn continuously     |
| What it is not  | Scrum, Kanban, or a closed methodology                        |
| Purpose         | Guide teams in uncertain and changing environments            |
| Management view | Less bureaucratic control, more value delivery and adaptation |

---

## 4 Values of the Agile Manifesto

| Value                                                 | Practical Meaning                                                              |
| ----------------------------------------------------- | ------------------------------------------------------------------------------ |
| Individuals and interactions over processes and tools | Aligned and collaborative people matter more than mechanically following tools |
| Working software over comprehensive documentation     | Real progress is usable delivery, not only documentation                       |
| Customer collaboration over contract negotiation      | Customer, business, and team must build shared understanding together          |
| Responding to change over following a plan            | Planning matters, but adapting is essential                                    |

---

## Agile Manifesto in Project Management

| Situation                 | Agile Application                                               |
| ------------------------- | --------------------------------------------------------------- |
| Requirement change        | Evaluate value, impact, and adjust the plan when it makes sense |
| Distant customer          | Bring stakeholders closer to the team                           |
| Too much upfront planning | Work in short cycles with frequent feedback                     |
| Excessive documentation   | Document only what supports decisions and execution             |
| Little real delivery      | Prioritize validatable increments                               |
| Team dependent on command | Create autonomy with clear direction                            |

---

## What to Memorize

| Question                         | Short Answer                                                             |
| -------------------------------- | ------------------------------------------------------------------------ |
| What is the Agile Manifesto?     | A set of values and principles for developing and managing adaptive work |
| Does it eliminate planning?      | No; it replaces rigid planning with adaptive planning                    |
| Does it eliminate documentation? | No; it prioritizes useful and sufficient documentation                   |
| Main measure of progress         | Working and validatable delivery                                         |
| Main management benefit          | More adaptation, collaboration, and value focus                          |
