# Português — Seção 6: Lean

## Resumo enxuto

| Tópico         | Ideia principal                                                                    |
| -------------- | ---------------------------------------------------------------------------------- |
| Lean           | Mentalidade de gestão focada em **gerar mais valor com menos desperdício**         |
| Lean Startup   | Validar hipóteses de negócio rapidamente antes de investir pesado                  |
| Lean Inception | Workshop para alinhar pessoas e definir um **MVP** claro                           |
| Lean UX        | Aplicar princípios Lean ao design e experiência do usuário                         |
| Foco de gestão | Reduzir desperdício, validar valor, melhorar fluxo e tomar decisões com evidências |

Lean parte da ideia de criar valor para o cliente com menos recursos e menos desperdício. ([Lean Enterprise Institute][2])

---

## Conceitos principais

| Conceito             | Explicação curta                                                 |
| -------------------- | ---------------------------------------------------------------- |
| Valor                | Aquilo que resolve um problema real do cliente ou negócio        |
| Desperdício          | Atividade que consome tempo, dinheiro ou esforço sem gerar valor |
| MVP                  | Versão mínima para testar uma hipótese de valor                  |
| Hipótese             | Suposição que precisa ser validada com dados ou feedback         |
| Aprendizado validado | Decisão baseada em evidência, não apenas opinião                 |
| Iteração             | Ciclo curto de construir, medir, aprender e ajustar              |

---

## Lean na gestão de projetos

| Situação                    | Como Lean ajuda                                      |
| --------------------------- | ---------------------------------------------------- |
| Projeto com muito escopo    | Ajuda a separar essencial de excesso                 |
| Muitas ideias sem validação | Força teste de hipóteses                             |
| Alto risco de retrabalho    | Valida antes de construir muito                      |
| Time sem foco               | Direciona energia para valor real                    |
| Stakeholders desalinhados   | Lean Inception ajuda no alinhamento do MVP           |
| Produto incerto             | Lean Startup ajuda a aprender rápido com baixo custo |

---

## O que memorizar

| Pergunta                        | Resposta curta                                       |
| ------------------------------- | ---------------------------------------------------- |
| Para que serve Lean?            | Para gerar valor reduzindo desperdícios              |
| O que é Lean Startup?           | Abordagem para validar hipóteses rapidamente         |
| O que é Lean Inception?         | Workshop colaborativo para alinhar visão e MVP       |
| O que é Lean UX?                | Aplicação de Lean ao design e experiência do usuário |
| Principal benefício para gestão | Evitar desperdício e tomar decisões com evidências   |

Lean Inception combina Design Thinking e Lean Startup para decidir o MVP, normalmente por meio de um workshop colaborativo. ([Caroli.org][3])

# English — Section 6: Lean

## Short Summary

| Topic            | Main Idea                                                                     |
| ---------------- | ----------------------------------------------------------------------------- |
| Lean             | A management mindset focused on **creating more value with less waste**       |
| Lean Startup     | Validate business hypotheses quickly before investing heavily                 |
| Lean Inception   | A workshop to align people and define a clear **MVP**                         |
| Lean UX          | Apply Lean principles to design and user experience                           |
| Management focus | Reduce waste, validate value, improve flow, and make evidence-based decisions |

---

## Key Concepts

| Concept            | Short Explanation                                          |
| ------------------ | ---------------------------------------------------------- |
| Value              | What solves a real customer or business problem            |
| Waste              | Any activity that consumes effort without creating value   |
| MVP                | Minimum version used to test a value hypothesis            |
| Hypothesis         | An assumption that must be validated with data or feedback |
| Validated learning | Decision-making based on evidence, not only opinion        |
| Iteration          | A short cycle of build, measure, learn, and adjust         |

---

## Lean in Project Management

| Situation               | How Lean Helps                                      |
| ----------------------- | --------------------------------------------------- |
| Too much project scope  | Helps separate essential work from excess           |
| Many unvalidated ideas  | Forces hypothesis testing                           |
| High risk of rework     | Validates before building too much                  |
| Team without focus      | Directs effort toward real value                    |
| Misaligned stakeholders | Lean Inception helps align the MVP                  |
| Uncertain product       | Lean Startup helps teams learn fast with lower cost |

---

| What is Lean Inception? | A collaborative workshop to align vision and MVP       |
| What is Lean UX?        | Applying Lean principles to design and user experience |
| Main management benefit | Avoid waste and make evidence-based decisions          |
